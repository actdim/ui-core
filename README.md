# @actdim/ui-core

Shared UI foundation, theme system, design tokens, adaptive layout, and Dynstruct component conventions for Actdim applications.

## Overview
- **Theme Engine**: Semantic CSS design tokens, PostCSS build-time generator, runtime variable overrides (`themeRuntime`), and compile-time class validator (`tw()`).
- **Adaptive Layout**: Screen tiers (`compact`, `medium`, `expanded`), orientation detection, safe-area insets, and prioritized hardware Back-Stack navigation.
- **Adaptive Overlays**: `AdaptiveDialog`, `ActionSheet`, and `AdaptiveMenu` with unified `onClose` contracts and two-way bound `open` states.
- **AI Guidelines**: Comprehensive developer and AI agent conventions for Dynstruct + MsgMesh development.
